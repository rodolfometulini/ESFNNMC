# data and source

Files contained in this folder: 

- `Agrimonia_stations.RData`: Comprehensive dataset relating air quality and livestock in Northern Italy (Fassò et al., 2023). 
https://zenodo.org/records/7956006 (Date of extraction: 14/11/2023)
- `georef-italy-regione-millesime.R`:  part of the Geographical repository maintained by Opendatasoft. 
This dataset contains data for regioni in Italy from 2019 to 2021. The data is sourced from ISTAT. 
https://data.smartidf.services/explore/dataset/georef-italy-regione-millesime/information/?flg=en-gb&disjunctive.rip_code&disjunctive.rip_name&disjunctive.reg_code&disjunctive.reg_name
